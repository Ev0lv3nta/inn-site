# Сайт по ИНН

Python-пайплайн для тестового DaData. Принимает ИНН и возвращает основной домен
или `null`, если связь не удалось подтвердить.

Поиск — собственный SearXNG, без платного поискового API. Анализ — Luna 6 через
OpenRouter, reasoning `high`. LLM платная; расходы небольшие и ограничены общим
бюджетом. Результаты живых проверок: [reports/validation.md](reports/validation.md).

## Запуск

Нужны Python 3.11+, [uv](https://docs.astral.sh/uv/), Docker с Compose
и ключ OpenRouter с доступом к `openai/gpt-6-luna`.
Движок Docker должен работать. Если Compose установлен отдельной командой
`docker-compose`, используйте её вместо `docker compose`. На macOS для запуска
Docker подойдёт бесплатный Colima.

```sh
uv sync --frozen
docker compose up -d --wait
export OPENROUTER_API_KEY='ваш_ключ'
uv run inn-site --inn 7721581040
```

```json
{"domain": "dadata.ru"}
```

JSON можно подать через stdin:

```sh
echo '{"inn":"7721581040"}' | uv run inn-site
uv run inn-site --inn 7721581040 --trace reports/private/example.json
```

В stdout только JSON. Код `0` — завершённый поиск, включая обоснованный отказ;
`2` — неверный вход; `3` — сбой поиска, LLM или таймаут. Причина сбоя идёт в stderr.
Трассировка сохраняет источники, цитаты, решения и расходы; в Git она не попадает.

## Что проверяется

Каталоги помогают найти название и ссылки. Затем пайплайн читает сам сайт,
включая контакты, юридические документы и текстовые PDF. LLM отличает оператора
сайта от клиента, партнёра и банка в платёжных реквизитах. Домен принимается,
только если дословная цитата с точным ИНН есть в прочитанной странице этого сайта.
Сниппет и чужая карточка этого не доказывают.

Модель выбирает, нужен ли новый поиск и на каком кандидате искать реквизиты.
Python ограничивает цикл: 3 поиска, 6 активных кандидатов, 12 URL, 4 минуты. Если обычное чтение
не удалось, доступен бесплатный Jina Reader без ключа. Учитывается robots.txt.
При нескольких подтверждённых собственных доменах ответ — `null`.

Кеш живёт сутки; `--no-cache` его отключает. Переменные перечислены в `.env.example`;
файл `.env` автоматически не загружается. `SEARX_URL` позволяет подключить готовый
SearXNG. Для имеющегося CRW есть `--search crw` и `CRW_URL`; частный сервер не нужен
для стандартного запуска. Адаптеры Exa и DDGS оставлены для сравнения поиска.

По умолчанию общий бюджет LLM — $0.25, журнал — `.cache/llm-spend.json`.
Перед запросом резервируется верхняя оценка расходов, после ответа учитывается
стоимость провайдера. Удаление журнала начинает учёт заново; это не лимит аккаунта.

## Проверка и документы

```sh
uv run pytest
uv run ruff check .
uv run python scripts/evaluate.py --split dev
uv run python scripts/evaluate.py --split holdout --no-cache
uv run python scripts/evaluate_llm.py
```

Первые две команды работают без ключа и сети. Остальные делают реальные запросы
и расходуют бюджет. Эталоны из `tests/cases.json` не передаются пайплайну.

[Теория](docs/theory.md), [описание реализации](docs/practice.md).
Один PDF с обоими ответами собирается так:

```sh
uv run --group docs python scripts/build_pdf.py
# После публикации:
uv run --group docs python scripts/build_pdf.py --github-url https://github.com/USER/REPO
```

Сайты без ИНН, сканы и закрытые страницы могут остаться без ответа. `null` не
доказывает отсутствие сайта. Бесплатный поиск зависит от индекса и ограничений
движков. Небольшой контрольный набор не заменяет оценку на выборке всего ЕГРЮЛ.

Код и документы подготовлены с Codex. Проверки и принятые решения сохранены в репозитории.
